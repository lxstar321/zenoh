Zenoh项目目录结构脑图
│
├── 项目概述
│   ├── Eclipse Zenoh: Zero Overhead Pub/Sub, Store/Query and Compute
│   ├── 网络通信框架，统一数据动态、数据存储、查询和计算
│   └── 版本: 1.6.2，基于Rust开发
│
├── 根目录配置&文档
│   ├── Cargo.toml & Cargo.lock
│   │   └── Rust工作空间配置，管理25+个crate
│   ├── README.md
│   │   └── 项目主要介绍文档
│   ├── CHANGELOG.md
│   │   └── 版本变更日志
│   ├── LICENSE & NOTICE.md
│   │   └── 开源许可证，EPL-2.0 OR Apache-2.0
│   ├── rust-toolchain.toml
│   │   └── Rust工具链版本指定(1.75.0)
│   └── clippy.toml & rustfmt.toml
│       └── 代码质量和格式化配置
│
├── 构建&CI系统
│   ├── ci/ 目录
│   │   ├── nostd-check/
│   │   │   └── 无标准库兼容化检查
│   │   └── valgrind-check/
│   │       └── 内存泄漏和线程安全检查
│   ├── build.rs
│   │   └── 构建时脚本
│   └── target/
│       └── 编译产物存储目录
│
├── 安全&认证系统
│   ├── certs/
│   │   └── 证书存储目录
│   ├── generate_mtls_certs.sh
│   │   └── MTLS证书自动生成脚本
│   ├── mtls_acl_config.json5
│   │   └── MTLS访问控制列表配置
│   └── MTLS_README.md & MTLS_TEST_README.md
│       └── MTLS功能说明文档
│
├── 测试&示例系统
│   ├── examples/ 目录
│   │   └── examples/ 子目录 (40+个示例)
│   │       ├── z_pub.rs & z_sub.rs
│   │       │   └── 基础发布订阅示例

│   │       │   └── 查询回复模式示例
│   │       ├── z_*_shm.rs
│   │       │   └── 共享内存传输示例
│   │       └── z_*_thr.rs
│   │           └── 多线程并发示例
│   ├── acl_*.py & auth_service.py
│   │   └── ACL测试脚本(Python)
│   └── start_router.sh
│       └── 路由器启动脚本
│
├── 核心模块
│   ├── zenoh/ - 核心协议库
│   │   ├── src/api/ - 公开API层
│   │   │   ├── session.rs
│   │   │   │   └── 会话管理
│   │   │   ├── publisher.rs & subscriber.rs
│   │   │   │   └── 发布订阅API
│   │   │   ├── querier.rs & queryable.rs
│   │   │   │   └── 查询回复API
│   │   │   ├── key_expr.rs
│   │   │   │   └── 键表达式处理
│   │   │   └── builders/ & handlers/
│   │   │       └── 构建器模式和处理句柄
│   │   └── src/net/ - 网络协议实现层
│   │       ├── routing/
│   │       │   ├── dispatcher/
│   │       │   │   └── 消息分发逻辑

│   │       │   └── interceptor/
│   │       │       └── 消息拦截器
│   │       └── protocol/
│   │           ├── linkstate.rs
│   │           │   └── 链路状态协议
│   │           └── network.rs
│   │               └── 网络协议实现
│   ├── zenoh-ext/ - 扩展组件库

│   │   │   └── 高级发布者
│   │   ├── advanced_subscriber.rs
│   │   │   └── 高级订阅者
│   │   ├── publication_cache.rs
│   │   │   └── 发布缓存
│   │   └── serialization.rs

│   └── zenohd/ - 路由器守护进程
│       ├── src/main.rs
│       │   └── 路由器程序入口
│       └── README.md
│           └── 路由器使用指南
